manip sur github

le principe

Git hub est un outil puissant !! C'est un service web d'hébergement et de gestion de développement de logiciel.
Pour collaborer sur un même code avec plusieurs personnes git hub permet de créer un dépôt (repository). Ainsi d'autres dev peuvent récupérer et modifier le projet.

les actions de base

Créer un repository

Créer un dépôt (repository) par l'interface de Github

Par l'interface dans Home > New

Un formulaire simple à comprendre avec : un nom Public/private gitignore

le nom du repository à créer

Public/private permet de partager sur internet avec Public ou garder l'acces pour soi en Private
